# Django Social Website Project

An image-sharing social application built with **Django 5** and **JavaScript**. This project implements user authentication, third-party social login, interactive image bookmarking, dynamic follower systems, and activity feeds.

---

## Project Overview

The primary objective of this project is to build an interactive social platform allowing users to discover and share images from across the internet. The project focuses on implementing robust backend structures with Django and interactive frontend components using JavaScript.

---

## Core Features

### 1. User Authentication System
*   User registration and login/logout workflows.
*   Profile management (creation and updating of user profile details).
*   Secure password change and password reset configurations.

### 2. Social Authentication
*   Third-party OAuth integration (e.g., **Sign in with Google**) to allow quick user registration and onboarding.

### 3. Image Sharing Engine
*   A centralized dashboard displaying shared images.
*   A client-side JavaScript bookmarklet allowing users to capture and post images directly from any external website to this platform.

### 4. Follower System
*   A relationship model mapping user-to-user connections (following/unfollowing other profiles).

### 5. Activity Stream
*   A dynamic feed showing actions (e.g., bookmarking images, following users) performed by the accounts a user follows.
